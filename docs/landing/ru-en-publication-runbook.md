# RU/EN — публикация и откат

Дата: 2026-11-05. Инструкция подготовлена; публикация, DNS и инфраструктура не изменялись.

## Подготовка

1. Зафиксировать согласованную версию исходников вместе с текущими финальными ресурсами каталога. Проверить, что незакоммиченные файлы входят в кандидат релиза.
2. Выполнить в landing: npm run check, npm test, npm run build:domains. Сохранить manifest.json и обе сборки как один кандидат релиза.
3. RU: dist-domains/ru → существующий хостинг www.dream-wheels.ru. EN: dist-domains/en → dreamwheels.pro. Уточнить действующий способ публикации на каждой площадке. Статические сборки не зависят от поддержки Vercel middleware на Timeweb.
4. Сохранить предыдущие полные артефакты и конфигурацию маршрутов. Выкладывать сначала на изолированную площадку приёмки. Не заменять целиком production webroot: сохранить существующие /app/**, /t/**, /api/backend/** и шлюзы Timeweb/Deno.
5. Публиковать только публичные Landing/Catalog, языковые preview и их ресурсы; dev/ — служебная страница и в публичный выпуск не входит. Переносить HTML вместе с соответствующими _astro и assets. Не удалять прежние хешированные ресурсы во время перехода.

## Перед включением

- Подтвердить правильный комплект на каждом домене: RU на www.dream-wheels.ru, EN на dreamwheels.pro. Существующий RU apex→www redirect должен совпадать с canonical; изменение DNS/redirect отдельным действием.
- Проверить HTTPS, / и /catalog, язык при противоположном Accept-Language, title, canonical, hreflang, отсутствие noindex на публичных страницах и наличие noindex у preview.
- Проверить locale switch с /catalog, #faq и разрешёнными UTM; проверить заголовки кеширования. HTML должен обновляться вместе с релизом, хешированные ресурсы могут кешироваться длительно. Не позволять общему кешу смешивать RU/EN.
- Проверить 360/390/768/1440, ресурсы, меню, FAQ, сравнение, каталог и честное состояние B2B. Проверить юридические и контактные ссылки, утверждённый текст для соответствующего рынка.
- Отдельно подтвердить работоспособность существующих маршрутов приложения/API. Готовность интеграции лендинга с приложением этим кандидатом не подтверждается; её включение отложено пользователем.

## Откат

При сломанной навигации, языке, ресурсах или маршрутах восстановить предыдущий полный комплект соответствующего домена и прежнюю конфигурацию публикации. Сбросить/перепроверить кеш HTML. Проверить /, /catalog и сохранённые маршруты приложения/API. Не откатывать только HTML без его ресурсов. Зафиксировать, какой комплект активен на каждом домене.

## Фактическая площадка — 2026-11-05

При публикации подтверждено через Vercel API и DNS: dreamwheels.pro, dream-wheels.ru и www.dream-wheels.ru относятся к проекту dream-wheels-ai-landing (prj_Zc70ETVBZ3exQfLrcFg4vNkTNNiV). RU apex уже перенаправляется 308 на www. Оба лендинга публикуются через этот проект Vercel; Timeweb и Deno для данного выпуска не меняются. Предыдущая инструкция о раздельной загрузке статических каталогов остаётся запасным сценарием для будущего переноса, а не описанием текущей инфраструктуры.

Доменные rewrite используют отдельные публичные HTML /localized/{ru,en}/ с preview=false. Прямой запрос внутренних путей получает X-Robots-Tag: noindex, follow; публичные / и /catalog индексируются и используют чистые ссылки. /ru и /en остаются локальными/прямыми preview с noindex.
