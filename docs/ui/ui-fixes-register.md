## Правки владельца от 25.10.2026 — локальная реализация

- Генерация: один заголовок; без верхнего статуса очереди, дублирующего пояснения и разделителя под фото; статус «Генерируем изображение» / «Generating image».
- Результат: повтор загрузки находится в области соответствующего недоступного фото; не запускает генерацию.
- Автомобиль: явное открытие редактора фокусирует первое обязательное незаполненное доступное поле; при заполненной форме — марку. Сохранение с next_action=select_vehicle_variant переводит на выбранный или первый доступный вариант комплектации.
- Исходная фотография существующей примерки не подменяется локально: удалены «Заменить фото», выбор файла и восстановление прежней локальной подмены.
- Распознавание получает оригинал с Telegram identity; ошибка получения фото отделена от неудачного распознавания.
- «Сохранить автомобиль» видна, но недоступна до готовности обязательных полей, включая рынок; неактивная кнопка имеет тёмный фон.
- Настройки: значки Email/Telegram. Мобильная гостевая Главная: «Войти» справа вровень с заголовком.
- URL resolver: недоступная страница отделена от неподдерживаемого документа; inline-подпись предлагает ручной ввод или другую ссылку. Avito при локальной проверке возвращает HTTP 439; успешный разбор этой страницы не заявляется.
- Системный вид select оставлен по решению владельца. Android-сбой раскрытия списка сейчас не воспроизводится; причина не установлена.

Публикация и реальная Telegram/защищённая API-приёмка выполняются отдельно после ревью. Генерации и платежи не нужны для локальных проверок.

Дополнение владельца: убрана вторая кнопка создания из пустого результата Главной; оставлены «Здесь будет ваша первая примерка» и пояснение. На экране генерации блок «Выбрано» показывает только название диска либо «Колёсный диск» / «Wheel», без номера примерки.


## Единый фокус форм — 25.10.2026

Текущее правило заменяет прежнюю остановку на заголовке редактора: при явном открытии сразу фокусируем ввод/выбор. Полная политика — `docs/ui/form-focus-policy-2026-10-25.md`.

- Ручные формы автомобиля/диска: первое обязательное незаполненное доступное поле, затем первое редактируемое.
- URL — поле ссылки; email/OTP — соответствующий ввод; параметр диска — поиск; комплектация — выбранный или первый доступный вариант.
- Сохранение переводит к следующему необходимому вводу или «Итогу»; ошибка валидации — к первому проблемному полю, общая ошибка — к сообщению текущего сценария.
- Нет конкурирующего legacy requestAnimationFrame при manual-vehicle. Pending-перенос отменяется взаимодействием пользователя и очищается при завершении/ошибке/уходе/смене примерки.
- Повтор оригинала при недоступном результате сохраняет устойчивую область original во время загрузки и после пяти redraw.
- Готовность сохранения вычисляется по текущим каталогам и рынку, а не сохранённому validation-флагу.

## Дополнение 25.10.2026 — одно сохранение ручных данных автомобиля

Решение владельца: ручной выбор → «Сохранить автомобиль» → комплектации; распознавание → проверка/исправление → «Подтвердить данные» → комплектации. Отдельное второе сохранение ручного ввода отменено. Сервер проверяет каталог и атомарно подтверждает присланные базовые поля, точная комплектация подтверждается отдельно.

Исправляются найденные staging E2E расхождения: чистый нормализованный черновик после перезагрузки не считается изменённым; сохранение диска при неподтверждённом автомобиле переводит к его форме вместо BODY. Подробный контракт и порядок публикации: [vehicle-save-confirmation-2026-10-25.md](vehicle-save-confirmation-2026-10-25.md).

## 26.10.2026 — запуск без вспышки legacy-интерфейса

- Первичный HTML скрывает старую оболочку до готовности runtime и новой поверхности. До этого отображается монохромный экран загрузки со спиннером и подписью в одну строку.
- Ошибка загрузки модуля или ожидание более 20 секунд показывает подпись и «Повторить», без раскрытия legacy. Поздний успешный запуск восстанавливает приложение. Фокус автоматически не переносится.
- Аватар восстановленной сессии в окне входа использует нейтральные цвета новой оболочки.
